# The task record

The single most reusable artifact in the whole OS. This is Nate B. Jones's Open Engine task record, reproduced close to whole because it works; the receipts vocabulary is his. Copy it into any task board an agent can read.

A prompt asks for output. A handoff explains the job. This is the handoff.

```text
Title:
plain task name (prefix with the agent's short name if you route by agent)

Requester:
the person who owns the outcome

Desired outcome:
what should exist when this is finished

Sources:
- what the agent should read
- what it should never invent

Acceptance criteria:
- specific check
- specific check
- where the output should be left

Boundaries:
- Do not publish, email, post, deploy, delete, change billing, or make
  customer-facing changes without human approval.
- Do not act outside the named sources, repos, or folders without asking.
- If the task needs judgement that is not stated here, ask before acting.

If blocked:
Ask one specific question on this same task, leave AGENT BLOCKED, and stop.
Do not create a second task just to ask the question.

Receipts:
- AGENT CLAIMED when work starts.
- AGENT BLOCKED when a specific answer belongs on this task.
- AGENT HUMAN HOLD when the answer needs the owner personally.
- AGENT RESUMED when the answer arrives and work continues.
- AGENT DONE when the scoped work is finished: what changed, where the
  output is, what was checked, what still needs a human.
- AGENT FAILED if the run breaks, with the last safe step.
```

The best first tasks end in review, not done: the agent gathers, drafts, and prepares; the human decides. That's how trust gets built.
