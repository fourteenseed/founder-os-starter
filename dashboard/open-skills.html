Open Skills

Reusable capability, not trapped chat history.

Open Skills are prompts, runbooks and operating methods that make the founder and their tools better over time. They solve the “Claude knows me but Codex doesn’t” problem by making context portable.

Skill rule

If you do the same thing twice, capture the method. If an AI answer was genuinely useful, turn the prompt and context into a reusable skill.

Runbook

Create daily founder brief

Turn signals into a short operating read: what changed, what matters, what needs a decision and what proof exists.

Handoff

Move work between AI tools

Package context, current state, constraints and output format so Codex or another tool can continue without starting cold.

Boundary

Public-safe extraction

Turn private work into a generic shareable pattern without exposing clients, family, money, transcripts or judgement.

Review

Token usage review

Ask which AI sessions created value, which repeated context, and which outputs should become templates.

Proof

Proof log update

Record what changed, shipped, sold, followed up or became reusable after each meaningful work block.

Seed review

Weekly seed posture

Decide which seeds to protect, grow, validate, park or harvest based on proof and founder capacity.
