# Workshop guide

1. Start with the company map.
2. Name the coherence problem.
3. Introduce Founder OS as the missing layer above individual AI tools.
4. Walk through the dashboard views.
5. Create a first founder context brief, Open Engine task, Open Skill and proof log entry.

## Five productivity gains

1. Stop repeating your context.
2. Make AI tools work as a team.
3. Turn scattered outputs into a daily operating brief.
4. Improve handoffs between tools, humans and sessions.
5. Track proof, not productivity theatre.
