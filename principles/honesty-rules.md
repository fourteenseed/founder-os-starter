# The honesty rules

These are the product. The rooms are just places the rules live. The first version of this OS died of breaking them; the second has held because it can't.

1. **Never fabricate a signal.** If the underlying data doesn't exist, the page shows a labelled placeholder and says what would make it real. A dashboard that invents freshness is worse than no dashboard: it spends your trust.

2. **Busyness is not progress.** No counts of jobs, outputs, or activity as if they were achievement. The only numbers allowed measure the human's progress or an agent's actual last run. (Your own assets — skills you own, thoughts your memory holds — are fine to count. The engine's self-importance is not.)

3. **One timestamp, one truth.** Every page states when its data was last true, once. If a refresh didn't run, the page says snapshot and says it plainly.

4. **Silence beats filler.** An assistant's line appears only when it has something genuine: a real handoff, a real decision, a real read. An empty section that explains its emptiness is a feature.

5. **Point, don't duplicate.** If the truth lives somewhere else — a task board, a calendar, a client-facing view — link to it. A page that mirrors another system will drift, and drift is quiet lying.

6. **Receipts on everything.** Agent work isn't done when the agent says done; it's done when there's evidence — what changed, where the output is, what was checked, what still needs a human.

7. **The human signs outward actions.** Drafts never send themselves. Publishing, deploying, and spending are signature doors.

8. **Prompts are content, and content goes stale.** Any stored prompt can be read before it's copied, and time-bound prompts carry a visible review-by date.

9. **Protect the human like the data.** Screen time is not progress either. Protected time — family, sport, rest, learning — is load-bearing, not leftover, and the system schedules nothing into it.
